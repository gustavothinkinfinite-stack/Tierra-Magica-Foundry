# A5 — Pueblos y Orígenes: resolución de diseño

Fecha: 2026-09-22.

## Decisión

Foundry T.M. no incorpora paquetes mecánicos obligatorios por pueblo, especie, cultura u origen.

La creación 1.0 ya dispone de una economía separada de **3 PR** y un catálogo de Rasgos para representar propiedades persistentes como Visión en la Oscuridad, Anfibio, Trepador Natural, Cola Prensil, Miembros Extra, Corpulento, Masivo, Afinidad Sobrenatural o Resistencia Ambiental. Esa capa cubre las diferencias fisiológicas o sobrenaturales que realmente deban tener efecto mecánico sin crear una segunda progresión paralela.

Los pueblos y Orígenes permanecen como identidad narrativa, procedencia, idioma, contactos, costumbres, posición social y ficción. No conceden automáticamente Atributos, Habilidades, PD, PR, Defensa, Vida, Maná, acciones, Técnicas ni competencias.

## Motivo

Los paquetes raciales/orígenes heredados del diseño previo no están ratificados por el Manual 1.0. Convertirlos en bonos gratuitos produciría tres problemas:

1. **Doble beneficio:** una propiedad podría obtenerse gratuitamente por pueblo y volver a comprarse como Rasgo.
2. **Elecciones dominantes:** bonos de Atributo, Defensa, Movimiento o competencias harían que ciertos pueblos fueran matemáticamente superiores para determinadas construcciones.
3. **Economía oculta:** un paquete gratuito rompería la comparación de personajes creados con los mismos 25 PD + 3 PR.

## Casos límite y salvaguardas

- Un rasgo anatómico no concede acciones adicionales salvo que su propia regla lo diga; `Miembros Extra` mantiene expresamente esa limitación.
- Un tamaño corporal distinto no concede por sí solo bonos genéricos de ataque, Defensa o daño: se usa la regla de Escala existente.
- Una cultura marcial no concede competencia gratuita; se compra con PD como cualquier otra Habilidad o Técnica.
- Una afinidad mágica no concede Disciplina, hechizos ni Maná adicional; puede representarse mediante `Afinidad Sobrenatural` cuando corresponda.
- Un origen privilegiado, militar, académico o criminal puede justificar contactos, equipo o ficción inicial sólo dentro de los presupuestos y límites normales de creación; no genera recursos mecánicos adicionales.
- Rasgos negativos de un pueblo u origen no generan PR adicionales, evitando optimización mediante desventajas irrelevantes.
- El DJ puede exigir un Rasgo cuando una capacidad fisiológica extraordinaria sea indispensable para la ficción del personaje, pero no puede cobrar dos veces por la misma propiedad.

## Balance

Esta resolución mantiene a todos los personajes sobre la misma base de 25 PD, 3 PR y 100 C, conserva el sistema sin clases y evita introducir una economía específica de ancestrías. También permite personajes atípicos dentro de un mismo pueblo sin obligarlos a compartir un paquete estadístico.

## Estado de canon

A5 queda **RESUELTO** para el núcleo 1.0: los paquetes mecánicos heredados de pueblos y Orígenes no se ratifican. El lore compatible puede conservarse. Las diferencias mecánicas necesarias se construyen exclusivamente con las reglas universales existentes, principalmente Rasgos, Escala, equipo, Habilidades y Técnicas.

No se añade ningún subsistema nuevo.
