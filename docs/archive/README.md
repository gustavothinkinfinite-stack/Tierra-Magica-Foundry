# Archivo documental — almacenamiento frío

Esta carpeta conserva documentación histórica, fuentes sustituidas, snapshots externos y documentos de proceso exclusivamente para **trazabilidad y recuperación excepcional**.

**Regla de uso:** no consultar `docs/archive/` como parte del flujo editorial normal. Si una idea archivada debe volver al proyecto activo, primero se compara con el Manual Maestro y luego se incorpora expresamente allí. Nada dentro de esta carpeta crea canon por sí mismo.

- `creacion/` — cierres y revisiones CREA.
- `crafting/` — cierres e implementación CRAFT.
- `catalogos/` — auditorías y sincronizaciones intermedias de catálogos.
- `audits/` — auditorías históricas y verificaciones especializadas.
- `releases/` — reportes RELEASE_READINESS de versiones anteriores.
- `historico/` — manuales, narrativa recuperada y documentos sustituidos.
- `fuentes_externas/` — registro y snapshots de referencias externas usadas durante consolidación.

La autoridad vigente está en `../Tierra_Magica_Manual_Maestro.md` y su jerarquía en `../FUENTES_CANONICAS.md`.
