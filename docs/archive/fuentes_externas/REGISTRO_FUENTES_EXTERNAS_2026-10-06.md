# Registro de fuentes externas — 2026-10-06

> **Estado:** almacenamiento frío / referencia de procedencia.  
> Ningún elemento de este registro sustituye a `docs/Tierra_Magica_Manual_Maestro.md`.

Este registro identifica las fuentes externas usadas durante la consolidación para que puedan dejar de formar parte del flujo de consulta habitual.

## Fuentes textuales externas

- `Foundry_TM_Guia_Estilo_Visual_v1.json` — guía visual v1.0. Referencia de identidad visual; no crea canon textual de reglas o historia.
- `Tierra_Magica_Inventario_Geografico_Canon_v1.json` — inventario geográfico derivado del Canon del Mundo integrado. Útil para procedencia y futura cartografía; el Manual Maestro prevalece.
- `Tierra_Magica_Sistema_Cartografico_v1.json` — sistema de trabajo cartográfico y control de estados canonical/provisional/proposal/unknown. Se conserva como metodología histórica; las decisiones geográficas sólo son canon cuando están ratificadas en el Manual Maestro.
- `pautas-como-reglas-de-trabajo-para-Foundry-T.M.txt` — principios de diseño y control de cambios usados durante el desarrollo. No constituye una fuente paralela de reglas.

## Regla de recuperación

Una fuente externa o histórica sólo debe volver a consultarse cuando:
1. sea necesario comprobar procedencia;
2. el Manual Maestro marque expresamente un área todavía abierta; o
3. se esté trabajando sobre arte/cartografía y se necesite su referencia específica.

Si un dato recuperado contradice el Manual Maestro, no se incorpora por inferencia: requiere una revisión explícita del canon.
