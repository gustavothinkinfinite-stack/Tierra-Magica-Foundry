## Regla de seguridad

El nombre de una variante no concede por sí solo:

- Daño adicional;
- Penetración adicional;
- menor FUE mínima;
- mayor alcance;
- ataques adicionales;
- Enganche;
- Derribo;
- Desarme;
- ni una interacción nueva con Técnicas.

Si alguna de esas diferencias se desea en el futuro, deberá abandonar el estado \`profile-variant\` y pasar por una auditoría mecánica explícita.
