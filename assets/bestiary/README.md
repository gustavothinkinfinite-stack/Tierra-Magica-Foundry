# Retratos y tokens del Bestiario (Foundry T.M.)

Colocar aquí los 20 archivos WebP aprobados del paquete `TM_Bestiario_GitHub_20_Imagenes_Aprobadas.zip`.

Archivos esperados: `civil`, `bandido`, `guardia`, `soldado`, `veterano`, `canalizador-hostil`, `lobo`, `ogro`, `centinela-de-bronce` y `troll-dominante`, cada uno con `-retrato.webp` y `-token.webp`.

El script de compilación verifica que cada pareja esté completa y sea WebP antes de incluir las rutas del arte en el Compendio Actor.

**No incorporar los bocetos del Tirador**. Su perfil canónico utiliza rifle, mientras que el boceto descartado muestra arco. Permanecerá con el icono genérico hasta disponer de una pareja correcta.

Este directorio es distribuido por `tools/stage-release.mjs` al incluir todo `assets/` y no debe contener versiones provisionales.

Para cargar los 20 archivos desde GitHub, entrar en esta carpeta, elegir **Add file → Upload files**, seleccionar los veinte WebP y registrar un commit. La mera presencia de este README no constituye la incorporación de imágenes.
